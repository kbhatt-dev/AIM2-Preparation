### Day 2 — Pandas Fundamentals ✅

Learned:

* `Series` and `DataFrame`
* Creating DataFrames from dictionaries
* `shape`, `columns`, `index`, `dtypes`
* `head()`, `tail()`, `info()`, `describe()`
* Column selection
* `loc` and `iloc`
* Boolean masks and filtering
* Multiple conditions
* Adding calculated columns
* `mean(axis=1)`

Key distinction:

```python

df[["Math"]]   # DataFrame

```
