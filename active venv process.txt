Create .venv
-> python -m venv .venv

Activate it
-> .\.venv\Scripts\Activate.ps1
After activation, your terminal should change to something like:
(.venv) PS C:\KRISHNA\WORKSPACE\AIM2-Preparation>

Verify
-> python --version
and:
where.exe python


upgrade pip:
python -m pip install --upgrade pip

install pckgs:
pip install numpy pandas matplotlib seaborn scikit-learn jupyter ipykernel

Verify installation:
pip list
